Renew Your License

How name search works

One name box, split into parts, each part matched on its own.

The portal asks for one thing: Your full name. License records keep the first, middle, and last name in separate fields, so the portal splits what the licensee types into those parts before it searches. The search then checks each part on its own. It ignores capital letters, accents, and punctuation, and it forgives small spelling differences.

Examples

The first word is the first name, the last word is the last name, and any words between are the middle name.

MariafirstJ.middleGarcialast

One word is always a last name.

Marialast

So a first name typed alone is searched as a last name: “Maria” finds last names such as Mariani. The results say “We searched for the last name Maria.”

A comma means the last name comes first.

Garcia,lastMariafirst

Without the comma, “Garcia Maria” searches for the first name Garcia and the last name Maria.

Jr., Sr., II, III, or IV at the end is the suffix.

MichaelfirstJohnsonlastJr.suffix

It works after a comma too: “Johnson, Michael Jr.”

A two-word first or last name still works.

The split can’t tell a middle name from half of a two-word name. So when there’s a middle name, the search also tries every other way to split the same words, and a license that matches any one of them is found.

As split
HenryfirstTaverasmiddleSanchezlast
Also tried
HenryfirstTaveras Sanchezlast
Finds Henry Taveras Sanchez
Henry TaverasfirstSanchezlast

A license is found when every part the licensee typed matches. A part left out isn’t checked.

First name

Starts with what was typed, or is a close spelling.

  • “Rob” finds Robert. “Catherine” finds Katherine.
  • “Bob” doesn’t find Robert.
Middle name

Starts with what was typed. An initial is enough.

  • “J” finds Josefina. Leave it out, and any middle name or none matches.
  • “J” doesn’t find a license that has no middle name.
Last name, 3 or more letters

Starts with what was typed, or is a close spelling.

  • “Garc” finds Garcia. “Jonson” finds Johnson.
  • “Smyth” doesn’t find Smith.
Last name, 1 or 2 letters

Is exactly what was typed, so a short name doesn’t bring back a crowd.

  • “Wu” finds Wu.
  • “Wu” doesn’t find Wulf.
Suffix

Is the same suffix, however it’s written.

  • “Jr” finds JR. Leave it out, and any suffix or none matches.
  • “Jr.” doesn’t find a license that has no suffix.

Never matters: capital letters, accents, and punctuation. “perez” finds Pérez, “Jr.” finds JR, and “Kevin O Brien” finds Kevin O’Brien.

The search compares short runs of letters in the two names. When enough of them line up, the names match. That forgives a missing, extra, or changed letter in a longer name. It doesn’t know nicknames, and it often misses a typo in a short name, where one wrong letter changes most of the runs.

Close enough

  • Garca finds García
  • Jonson finds Johnson
  • Thomson finds Thompson
  • Catherine finds Katherine
  • Rodriquez finds Rodriguez
  • McDonald finds MacDonald
  • Mariana finds Maria

Not close enough

  • Micheal doesn’t find Michael
  • Jon doesn’t find John
  • Smyth doesn’t find Smith
  • Stephen doesn’t find Steven
  • Mike doesn’t find Michael (nickname)
  • Bob doesn’t find Robert (nickname)

Close spelling applies to the first name and to a last name of 3 or more letters. The middle name and suffix don’t use it.
I typed a first name and got nothing, or the wrong people.
One word is always a last name, so Maria searches for last names such as Maria and Mariani. The results say which last name was searched. Type the first and last name.
The first name I typed came back as the last name.
It was typed alone, or the name was typed last name first without a comma. Type the first name first, or use a comma: Garcia, Maria.
Adding a middle initial made the license disappear.
A typed middle name has to match. If the license has no middle name, or a different one, leave it out. Leaving it out never hides a license.
A nickname didn’t work.
Search uses the name on the license. Rob finds Robert because Robert starts with Rob. Bob doesn’t.
A typo didn’t match.
Close spelling catches small differences, not every typo. Short names and swapped letters are the usual misses.
Too many results came back.
Add the first name. If the list still mixes licenses, the results screen asks for the license type, then the ZIP or postal code, each only when it tells the licenses apart. They narrow the list; they don’t change how the name matches.
